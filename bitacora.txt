El uso de Html, CSS y JS, se vera reflejado de la siguiente manera

HTML es la base de la pagina un ejemplo de este es la informacion principal de Rueda libre
CSS es la parte visual la que ayudara que la informacion principal se vea de manera ordenada y coherente
JS es la parte de acciones la que permitira que algunas acciones dentro de la pagina redireccionen datos o los almacenen en la nube
